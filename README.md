# 👨🏻‍💻 Kauê Messias

**`Engenheiro de Dados`**

Me chamo Kauê Messias, sou de São Paulo - SP e atuo como profissional de dados com experiência prática no setor bancário e industrial. Atualmente, curso **Análise e Desenvolvimento de Sistemas** e **Inteligência Artificial e Machine Learning**.

Minha jornada na área começou estruturando um setor de Business Intelligence do zero e desenvolvendo automações em Python (ETL). Tenho passagem recente pelo **Itaú Unibanco**, onde atuei no desenvolvimento de pipelines de dados e machine learning utilizando o ecossistema AWS (SageMaker e S3), ingestão via Apache Kafka e extração com SQL distribuído (Trino/Presto).

Estou em transição estratégica e focado em projetos de **Engenharia de Dados**, aprofundando meus conhecimentos e certificações em arquitetura Cloud, orquestração (Apache Airflow), transformação (dbt), Data Warehouses e processamento distribuído (Databricks, GCP/BigQuery).
